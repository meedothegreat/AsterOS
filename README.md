# AsterOS
Hello! I'm dedicated to building an OS that runs .exe and .dlls for free! I'm willing to make it open source, unfortunately it's still in beta. 
- I'll be releasing a new version whenever I can so stick around.

- v0.1.0
  Developed the kernel and graphical interface. Known bugs: No mouse movement (desktop in development)
28/10/26
  Uploaded Source Code for v0.1.0
- v0.2.0
  Uploaded Source code and complete files + ISO of AsterOS (no mouse movement yet)
**New Features in v0.2.0**
Graphical UEFI installation interface with explicit disk-erasure confirmation.
GPT partitioning and FAT32 EFI installation code.
Preinstalled virtual disk image.
Experimental mouse support and clickable interface navigation. (doesnt work yet)
Native text editor with file-saving functionality in RAM.
File management commands for copying, renaming and editing files.
Additional installer, filesystem and binary verification tests.
